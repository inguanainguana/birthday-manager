О приложении

Приложение предназначено для ведения списка дней рождения близких и коллег, планирования подарков и контроля связанных с ними расходов. Реализовано на Spring Boot с использованием Spring MVC, Spring Data JPA, Spring Security, Thymeleaf и Bootstrap.

Технологии
Java 17 Spring Boot 3.x Spring Security Spring Data JPA Hibernate MySQL Thymeleaf Bootstrap Lombok Maven
